# Local Agentic AI CDC Health Mortality Tracker & Analyzer

A fully local agentic AI system that fetches real-time CDC mortality data, cleans & analyzes it, and provides human-friendly health recommendations.

## 🔧 Setup Options

We support two local LLM configurations:

- [TinyLlama Setup Instructions](./README-TinyLlama.md)
- [Ollama (Recommended) Setup Instructions](./README-Ollama.md)

**Note:** For optimal performance and more consistent results, we recommend using the [Ollama setup](./README-Ollama.md).
